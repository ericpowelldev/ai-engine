# knowledge/

General, org-agnostic reference knowledge: facts worth keeping that aren't rules ("do X") and aren't personal ("who the user is"). Think reference material an agent should consult when a task touches the subject.

- **Org-specific knowledge** — glossaries, repo maps, system gotchas — lives in the owning module's `knowledge/`, not here.
- **Personal details** live in `personal/`.
- Knowledge is fact-shaped; if an entry keeps reading as an instruction, it's a rule — move it to `rules/`.

This folder is committed and shared, so keep entries generic and user-neutral.
