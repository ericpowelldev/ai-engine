# personal/

Who the user is: identity, role, preferences, terminology, and phrases. Seeded by the user (usually via `/setup`), read during orientation and whenever user context matters.

## Privacy

Everything in this folder except this README is **gitignored** — automatically local, never committed, no naming convention needed. This is the one place in the repo where the user is named directly; all committed content stays user-neutral.

## What goes here

- `about.md` — who the user is: role, background, how they like to work.
- `terminology.md` — words and phrases the user uses and what they mean.
- Anything else personal that should shape sessions but never ship.

Personal content is root-only: modules have no `personal/` folder.
