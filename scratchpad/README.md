# scratchpad/

Brainstorming space for isolated ideas that have no home in a current directory or project. Each idea gets its own subfolder; everything inside is loose working material, not deliverables.

- One folder per idea, named for the idea.
- Contents except this README are **gitignored** — scratch is local by nature.
- Org-specific scratch lives in the owning module's `scratchpad/`.
- When an idea graduates into real work, its material moves out to wherever that work lives; the scratch folder can then be deleted.
